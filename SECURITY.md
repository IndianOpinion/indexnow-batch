# Security policy

## Supported versions

| Version | Supported |
|---|---|
| 0.1.x | Yes |

## Reporting a vulnerability

Please email **hello@indianopinion.org** with "indexnow-batch security" in
the subject. Do not open a public issue for a vulnerability.

Include the version, a description, steps to reproduce, and the impact as
you see it. We will acknowledge your report within 3 working days and aim
to send a fix or a mitigation plan within 14 days. We will credit you in
the release notes unless you prefer otherwise.

## Scope notes

The IndexNow key is a proof of ownership and is public by design in the
key file. A report that the key file can be fetched is not a
vulnerability. A way to make the plugin serve something other than the
current key, announce a URL it should not, or act without the
`manage_options` capability is.
